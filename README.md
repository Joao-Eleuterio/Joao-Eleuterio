## Research

My MSc research explored **differential stroke assessment using SERS and machine learning**, with GFAP as a biomarker.

The work included:

- preprocessing Raman spectra with Savitzky–Golay filtering;
- dimensionality reduction using PCA;
- spectral feature engineering;
- supervised classification with LightGBM;
- repeated holdout validation on large-scale spectral data.

A related research article was published in **Biosensors (2025)**.
